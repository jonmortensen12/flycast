Flycast remote

Every setting the headset menu has, on this phone, so you can adjust the river for somebody who has never held a fly rod without talking them through a menu they cannot reach.

On the headset: press Phone remote on the front page before handing it over, or open the in-VR menu with Y and push right on Phone remote under PRESETS. A four-letter code appears along the top of the panel.

Both devices need to be on the same wifi. The code changes every time the room is opened.
